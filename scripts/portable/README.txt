FileSeal, portable version
==========================

Run FileSeal.exe. Nothing to install, no administrator rights needed.

- Settings, logs and WebView2 data are kept in the "data" folder, created
  next to FileSeal.exe at the first start. Nothing is written in your
  profile. To move FileSeal, move the whole folder.
- New databases are proposed next to FileSeal.exe. A database on the same
  drive as FileSeal.exe is found again when the drive gets another letter
  (a USB key on another PC).
- Needs the WebView2 runtime, part of Windows 11 (on Windows 10, install
  "Microsoft Edge WebView2 Runtime" if FileSeal does not start).
- Windows may warn that the program is not signed (SmartScreen): "More
  info", then "Run anyway".
- Without the portable.flag file, FileSeal keeps its settings in your
  profile, like the installed version.


FileSeal, version portable
==========================

Lancez FileSeal.exe. Rien à installer, aucun droit administrateur requis.

- Réglages, journaux et données WebView2 sont gardés dans le dossier
  « data », créé à côté de FileSeal.exe au premier lancement. Rien n'est
  écrit dans votre profil. Pour déplacer FileSeal, déplacez tout le dossier.
- Les nouvelles bases sont proposées à côté de FileSeal.exe. Une base sur le
  même disque que FileSeal.exe est retrouvée quand ce disque change de
  lettre (une clé USB sur un autre PC).
- Nécessite le runtime WebView2, présent dans Windows 11 (sous Windows 10,
  installer « Microsoft Edge WebView2 Runtime » si FileSeal ne démarre pas).
- Windows peut prévenir que le programme n'est pas signé (SmartScreen) :
  « Informations complémentaires », puis « Exécuter quand même ».
- Sans le fichier portable.flag, FileSeal garde ses réglages dans votre
  profil, comme la version installée.
